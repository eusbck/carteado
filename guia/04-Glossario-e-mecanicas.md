# Glossário em português e mapa de mecânicas

As traduções abaixo ajudam a ler cartas em idiomas diferentes. Alguns nomes mais novos são mantidos em inglês para evitar apresentar uma tradução não confirmada como nomenclatura oficial. O **glossário integral oficial em inglês** está em `dados/glossario-oficial.json`, no TXT e na busca local. Consulte também [palavras-chave comuns em português](https://magic.wizards.com/pt-BR/keyword-glossary).

## Vocabulário de mesa

| Português / termo comum | Inglês | Significado prático |
| --- | --- | --- |
| Conjurar | Cast | Colocar uma mágica na pilha seguindo anúncio e pagamento. |
| Jogar | Play | Pode ser conjurar uma mágica ou jogar um terreno; contexto importa. |
| Ativar | Activate | Pagar o custo de uma habilidade ativada. |
| Disparar / desencadear | Trigger | A condição de uma habilidade desencadeada aconteceu. |
| Resolver | Resolve | Executar um objeto do topo da pilha após os passes. |
| Prioridade | Priority | Permissão para fazer uma ação naquela janela. |
| Jogador ativo | Active player | A pessoa cujo turno está acontecendo. |
| Pilha | Stack | Zona de mágicas e habilidades aguardando resolução. |
| Grimório | Library | Seu deck de compra, em ordem, normalmente de face para baixo. |
| Campo de batalha | Battlefield | Zona das permanentes em jogo. |
| Cemitério | Graveyard | Zona de cartas descartadas, destruídas etc., conforme os eventos. |
| Exílio | Exile | Zona diferente do cemitério e de fora do jogo. |
| Zona de comando | Command zone | Zona compartilhada onde ficam comandantes e outros objetos pertinentes. |
| Permanente | Permanent | Objeto no campo; não confunda com a mágica na pilha. |
| Ficha | Token | Objeto criado por um efeito, sem uma carta convencional correspondente. |
| Alvo | Target | Escolha identificada como alvo pelas regras/texto; tem teste de legalidade. |
| Virar / desvirar | Tap / untap | Mudar o estado pertinente, geralmente girando a permanente. |
| Poder / resistência | Power / toughness | Características de criatura; dano fica marcado separadamente. |
| Marcador | Counter | Contador colocado em jogador/objeto; não é “anular”. |
| Anular | Counter a spell | Retirar uma mágica/habilidade da pilha por um efeito apropriado. |
| Custo de mana | Mana cost | Os símbolos do custo da carta. |
| Valor de mana | Mana value | Número derivado do custo conforme regras, diferente do total pago. |
| Identidade de cor | Color identity | Restrição de construção de Commander; não é só a cor atual. |
| Enjoo de invocação | Summoning sickness | Apelido da restrição de tempo de controle para ataque e símbolos de virar/desvirar de criaturas. |
| Entrar no campo / ETB | Enters / ETB | Evento de entrada; gatilhos e substituições de entrada são diferentes. |
| Morrer | Dies | Uma criatura foi do campo ao cemitério. |
| Sacrificar | Sacrifice | Seu controlador põe a permanente no cemitério; não é destruição. |
| Blink | Blink / flicker | Apelido de exilar e devolver, normalmente criando um objeto novo. |
| Fora de fase | Phased out | Estado que não é uma mudança comum de zona. |
| Ação de estado | State-based action / SBA | Verificação automática antes de prioridade. |
| APNAP | Active Player, Nonactive Player | Ordem do ativo e depois dos demais na ordem do turno. |
| Custo adicional | Additional cost | Somado ao custo, inclusive quando o custo de mana não é pago. |
| Custo alternativo | Alternative cost | Substitui o custo de mana segundo a permissão da carta. |
| Texto Oracle | Oracle text | Texto oficial atual da carta, que pode diferir da impressão. |
| Ruling | Ruling | Esclarecimento oficial de uma carta/interação. |
| Singleton | Singleton | Regra de uma carta por nome, salvo exceções. |

## Tipos de ficha frequentes

Tesouro produz mana sacrificando como custo de uma habilidade de mana válida. Pista normalmente paga {2} e sacrifica para comprar, usando a pilha. Comida normalmente paga {2}, vira e sacrifica para ganhar 3 de vida, usando a pilha. Sangue normalmente envolve pagar, virar, descartar e sacrificar para depois comprar; leia a definição. Mapa, Powerstone, Gold, Lander e fichas recentes também têm definições próprias. A lista completa de fichas predefinidas está em **CR 111.10**.

Uma ficha pode ser criatura, artefato, encantamento etc. Não presuma que toda ficha seja criatura nem que todas as habilidades de fichas resolvam imediatamente. As cores, características e habilidades vêm da instrução que a criou e das regras aplicáveis.

## Como encontrar todas as outras mecânicas

O arquivo `dados/indice-mecanicas.json` contém **cada subseção de ação com palavra-chave (701) e habilidade com palavra-chave (702)** encontrada nesta versão. A busca do portal pesquisa tanto regras quanto o glossário oficial. Isso inclui mecânicas antigas, pouco comuns e recentes — sem restringir a base apenas às habilidades listadas nesta cola.

As estruturas especiais restantes possuem capítulos próprios: cartas duplas 709; flip 710; leveler 711; duas faces 712; substitutas 713; Saga 714; Adventure 715; Classe 716; Attraction 717; Prototype 718; Case 719; Omen 720; Station 721; Preparation 722; controlar jogador 723; encerrar turnos/fases 724; monarca 725; iniciativa 726; reiniciar 727; rad 728; subgames 729; merge 730; dia/noite 731; atalhos 732; ações ilegais 733. A inclusão no manual não significa que qualquer carta dessas categorias seja legal em qualquer deck de Commander.
